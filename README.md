# HR_Analytics---DB

HR Analytics Dashboard

An interactive HR Analytics Dashboard developed in Microsoft Excel to analyze workforce data and employee attrition. This dashboard provides a comprehensive overview of key HR metrics, including employee count, attrition rate, department-wise performance, salary distribution, age groups, gender-wise attrition, and job role satisfaction. With interactive slicers and dynamic visualizations, it enables users to explore HR trends and gain actionable insights for better workforce planning and decision-making.

Tools Used
  
  Microsoft Excel
  Pivot Tables & Pivot Charts
  Slicers
  Data Visualization
  
  
Key Features

  KPI Cards (Total Employees, Active Employees, Attrition Count, Attrition Rate, Average Age & Experience)
  Department-wise Employee Analysis
  Attrition Analysis by Department, Gender & Salary
  Job Role & Satisfaction Analysis
  Age Group Distribution
  Interactive Department Filter
